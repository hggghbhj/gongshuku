# 工书库自动健康检测说明

## 脚本位置
`crawl/check_pdf_health.py`

## 功能
- 多线程10并发检测所有7540份PDF是否能正常打开在线预览
- 检测项：HTTP状态码、%PDF头、Content-Type、文件大小
- 自动修复：URL中文编码、相对路径补全、Referer防盗链、SSL忽略
- 输出报告：`crawl/pdf_health_report.json`

## 运行方式
```bash
cd crawl && python3 check_pdf_health.py
```

## 异常原因说明
- `http_403`：目标网站防盗链/WAF屏蔽云IP（如金田、普传、鼎阳）
- `http_404`：文件已删除或链接失效（如海为官网改版）
- `not_pdf`：返回HTML而非PDF（多为SPA fallback）
- `http_567`：自定义错误码（多为CDN拦截）
